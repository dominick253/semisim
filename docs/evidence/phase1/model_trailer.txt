NODE_COUNT is 12 rather than 11 because Godot wraps the GLB root in a Node3D
named after the file (`trailer`); the GLB itself holds 11 nodes (root `Trailer`
plus 7 meshes and 3 pivot empties). The tractor file carries the same wrapper
(NODE_COUNT 28 for 27 GLB nodes), so this is importer behavior, not a defect.

Reading: every anchor lands on its pinned coordinate. kingpin at (0, 1.30, 0.0)
is KINGPIN_TRAILER_LOCAL and, with the trailer origin placed 1.00 m forward of
the tractor origin (D34), the coupling point the coupling controller measures.
trailer_ref at (0, 1.60, 6.00) is TRAILER_REF_LOCAL. landing_contact at
(0, 0.35, -1.20): y is the pinned stroke (LANDING_CONTACT_HEIGHT_M), x and z
are this slice's decision, recorded as D46. The model is upright: world bounds
span y 0.000 to 4.070, x plus and minus 1.295, z -2.400 to 13.750, which is
exactly the 53 ft box envelope (2.59 x 4.07 x 16.15 centered at (0, 2.035,
5.675)). No VehicleWheel3D node exists in the imported trailer, so the four
TrailerWheel nodes import as plain MeshInstance3D, which is what the raycast
suspension wheel design requires.

The four wheel meshes were measured as world AABB centers (parent re-run, a
check the build pass did not make): each sits at x plus or minus 1.050, which
is TRACK_HALF_TRAILER_M, on the pinned bogie axles z 9.600 and 10.400, at y
0.563 with a measured vertical radius of 0.563. The model wheels are therefore
coaxial with the physics wheels rather than merely near them. The trailer x was
already on the pinned track; D48 moved the node origins, which tests/scratch/
wheel_origins.gd now measures equal to the centers above to three decimals.

## Required node names

Present in the GLB: `Trailer`, `CargoBox`, `TrailerWheelFL`, `TrailerWheelFR`,
`TrailerWheelRL`, `TrailerWheelRR`, `TrailerKingpin`, `LandingGear`, plus the
pivot empties `kingpin`, `landing_contact`, `trailer_ref`. No node or pivot
name ends in `wheel` (D44), and the export went through
cityhaul_blender.export_glb with export_yup=False (D45).

## Decision recorded in this slice

D46: the spec pins the landing gear stroke height (0.35 m) but never its x and
z. landing_contact sits at (0, 0.35, -1.20): 1.20 m behind the kingpin plate
is the standard 53 ft van landing gear position and it sits inside the box
footprint (z -2.40..+13.75). The LandingGear mesh is built on this point,
legs bottoming at y 0.35.

## Materials

No third-party texture was fetched in this slice, so the model ships plain PBR
metallic and roughness materials: white van box, dark tires, bare aluminum
kingpin plate and landing gear, steel kingpin pin. Nothing licensed is used,
so `docs/ATTRIBUTION.md` gains no entry from this slice.
