Defects fixed
-------------
1. The spec pins the restart path twice (5.4: the spring brake holds "until
   pressure recovers above 60 psi or the engine is restarted"; section 6:
   "Recovery only via restart"), but AirSystem.restart_engine() had zero
   production callers and combination_controller.gd set engine_running = false
   at the 1900 rpm shutdown with nothing ever setting it true again: one
   over-rev was a permanently dead truck with a stopped compressor.
2. restart_engine() set spring_brake_engaged = false and then called
   _refresh_state(), which re-engaged the brake unconditionally below 40 psi:
   at any pressure below 40 psi the restart cancelled its own release. The
   sub-40 psi engage is now suppressed while a restart release latch
   (_restart_released) is active, and the latch clears once the pressure
   recovers past the 60 psi release point, so a later sub-40 psi drop
   re-engages the brake. The no-restart ladder is byte-identical (T9/T10
   unchanged) and the engine-running 30 psi engage that the audio hiss test
   encodes still fires.

The restart rule (combination_controller.gd, _step, immediately after the
shutdown check)
-------------------------------------------------------
  if not engine_running and engine_rpm <= PHYSICS_CONSTANTS.ENGINE_IDLE_RPM and throttle <= 0.0:
      engine_running = true
      air.restart_engine()

DrivelineModel.engine_rpm_from_wheel_rate clamps to at least idle, so
engine_rpm <= ENGINE_IDLE_RPM means both the wheel side and the vehicle side
have fallen to the idle floor (the combination is essentially stopped), and
throttle <= 0.0 stops the rule re-firing straight back into the over-rev that
killed it. The check runs after the shutdown, so the shutdown wins on the
killing tick (1900 rpm, far above idle). D54.

Probe: tests/scratch/engine_restart_probe.gd
--------------------------------------------
Settle the rest harness (throttle 0 during the settle), force
c.engine_running = false once, then 30 s in locked gear 1: throttle 1.0 for
the first 10 s, released for the remaining 20 s. The split is deliberate: the
restart rule requires the throttle released, so a pure 30 s hold can never
show the restart landing; the first 10 s prove the hold blocks the restart
(test 2's condition) and the release shows it land (test 1's condition).

drift decaying under rolling resistance):

Follow-ups (recorded, not fixed)
--------------------------------
1. AirSystem.consume_psi() has no production caller, so pressure never falls
   in play and the 60/40 psi ladder is still decorative: the only live air
   state transition in play is the refill in step(). Related latent coupling:
   air.engine_running is never set false by the controller on shutdown (only
   reset() and restart_engine() write it), so the sub-40 psi re-engage while
   the engine is actually off is reachable only through test code until
   consume_psi gets a caller.
2. jackknifed latches with no release path.
