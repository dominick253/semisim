Reading: every anchor lands on its pinned coordinate. cab_eye at y 2.10 z -4.20
matches D1. kingpin and fifth_plate share (0, 1.30, -1.00), which is D2 and is the
coupling point the coupling controller measures. Steer axle z -6.50 at radius
0.554 and drive axle z 0.00 at radius 0.563 match physics-spec section 2. The
wheel pivot empties and the four wheel node origins both sit on the pinned track
plane x plus or minus 1.100 (TRACK_HALF_STEER_M, TRACK_HALF_DRIVE_M; D48), and
tests/scratch/wheel_origins.gd measures each wheel node origin equal to its mesh
center to three decimals. The model is upright: world bounds run y 0.000 to
3.100, x plus and minus 1.450 at the mirrors (the tyres now run plus and minus
1.2475), z -7.054 to 0.563, which is a 7.6 m tractor on a 6.5 m wheelbase. No
VehicleWheel3D node exists in the imported tractor, which is what the raycast
suspension wheel design requires. The upright check measures the Cab mesh bounds
(y 0.950 to 2.650, z -5.000 to -3.300, so the cab sits between the steer axle at
z -6.500 and the drive axle at z 0.000). It does not read the Cab node transform:
that origin is at the model origin, and the first version of the probe reported
false for a model that was already upright.

## Two defects this slice found, both fixed in the pipeline

1. Export orientation. `cityhaul_blender.export_glb()` used `export_yup=True`. In
   Blender 4.5.1 that applies a -90 deg rotation about X on export, so a model
   built upright in the Godot convention lands nose down: Godot position =
   (Blender.x, Blender.z, -Blender.y). The first build hid it behind a +90 deg
   rotation on the Tractor root, and the earlier smoke run never caught it because
   only triangle counts were measured. The helper now exports with
   `export_yup=False` and the build script carries no compensating rotation.
   Logged as D45.
2. Pivot name collision. Godot 4.7.2's glTF importer converts any node whose name
   ends in `_wheel` or `-wheel` into a `VehicleWheel3D` and strips the suffix, so
   `fifth_wheel` imported as a physics node named `fifth` and the contract name
   never survived. Measured name mapping from the build slice:
   `fifth_wheel` to `fifth` (VehicleWheel3D), `fifth-wheel` to an anonymous
   VehicleWheel3D, while `fifthwheel` and `wheel_fifth` survive as plain Node3D.
   The pivot is renamed `fifth_plate`, and the imported model now reports zero
   VehicleWheel3D nodes. Logged as D44.
